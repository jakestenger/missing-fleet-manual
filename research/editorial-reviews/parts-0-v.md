# Parts 0–V: reader-focused editorial review

2026-09-09. Baseline: `73aa2cc` on main. Working branch: `style/parts-0-v-reader-pass`.

## Scope and voice

Revised all 45 remaining prose chapters in Parts 0–V in both the living 4.91 edition and frozen 4.90 edition. The approved prose of 0.1, Who Fleet is, and 0.2, What Fleet is, remains intact; 0.2's screenshot request was normalized. All 47 chapters were considered for screenshots.

The chapters now begin with the administrator's task and the practical value of the feature, then explain the mechanism and its limits. The pass keeps enough context and transitions for a friendly, useful manual. It removes repeated rhetorical corrections, scolding cautions, bold announcements that immediately reverse themselves, and commentary about how the chapter was written. Technical procedures, platform distinctions, and recovery requirements remain.

A final sweep renamed 63 topic headings in each edition to make the navigation more direct. Internal links were updated and the old HTML anchors were retained for published bookmarks. The appendix capability index received link-only changes where it pointed to those headings. No Parts VI–VIII narrative or appendix reference tables were rewritten.

Screenshot navigation was checked against the existing chapters, with targeted checks of the 4.91 frontend for certificate-authority navigation, the policy list's refresh timestamp, the report schema browser, batch script selection, and Apple MDM command history. Final UI and edition verification still happens when the real images are captured and reviewed.

## Targeted consistency clarifications

These are narrow corrections made while editing, not a fresh source audit of the whole manual. Existing `verified_*` provenance was preserved.

- **3.3, Windows placement:** the living edition now accounts for the 4.91 default-fleet assignment during linking of a new user-driven MDM-first host, rather than saying a global secret always leaves it Unassigned. Existing hosts retain their placement. The source check and eligibility are recorded in the [3.3 ledger](../section-notes/3.3-notes.md).
- **5.1, rollout rings:** labels apply where the selected mechanism supports them. Built-in OS-update enforcement is fleet-scoped, as 5.6 already explains.
- **5.2, user-channel declarations:** the two-hour grace period holds a pending declaration while an automatically enrolled Mac obtains a user channel; it does not make immediate failure the expected result. The existing [5.2 ledger](../section-notes/5.2-notes.md) already records the hold and failure branches.
- **5.3, script enablement:** effective agent configuration controls script support. Packaging supplies defaults and does not create a permanent inability to enable it later. The [5.3 ledger](../section-notes/5.3-notes.md) records the clarification and the source paths.
- **5.4, installer downloads:** the 4.91 overview includes the presigned GCS path already covered in deployment. Its targeted source check is in the [5.4 ledger](../section-notes/5.4-notes.md); frozen 4.90 remains unchanged.
- **5.5 and 5.9, timing:** timing descriptions distinguish when an interval is measured from and when Fleet can evaluate it. An ordinary policy interval is not an absolute upper bound for an offline or delayed host.
- **5.7, offline actions and Linux wipe:** an offline device can receive queued work later. Waiting out Linux's delayed deletion phase alone does not prove deletion completed, consistent with the chapter's description of early success.
- **5.8, credential reads:** the managed local administrator password's reveal-triggered rotation is explicitly macOS-only, preserving the 4.91 Windows distinction documented in 5.5.
