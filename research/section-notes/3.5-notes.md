## Derived

- **"One channel and it is MDM"** as the chapter's frame is the deliberate third variation on 3.2's two channels, 3.3's two coupled channels and 3.4's one agent channel.
- **"One link per fleet"** and **"the link is a credential"** follow from the secret being a query parameter that decides placement. Fleet does not warn about either.
- **"An iPhone that completes ADE is done"** follows from there being no fleetd install command on this platform, which is what makes the macOS half-enrolled state impossible here.

## Not claimed

- **Whether ADE is usable on Fleet Free for these devices.** Same unresolved licensing question 3.2 records, and handled the same way.
- **What decides fleet placement on the account-driven path.** Not traced. The chapter does not assert one.
- **The enrollment URL panel's release.** 4.90.0's note covers the macOS tab only; the iOS and iPadOS links predate it and the exact release was not established, so no version-note row was written for it.

## Errors this chapter found elsewhere

**8.1 said macOS enrollment types are "ADE/ABM, manual profile, or account-driven".** Account-driven is iOS and iPadOS only, which 8.13 had already been corrected for. The row now separates the two platforms and says so. Found by `claims.py`, not by review, and it is the third instance of this same claim needing correction in a different chapter.
