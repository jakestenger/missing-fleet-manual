## Verified facts

### Managed cloud hosting is gated, and the stub omitted it
`docs/Get started/FAQ.md`, "Can you host Fleet for me?":

> Fleet offers managed cloud hosting for **Fleet Premium** customers with large deployments.
> While organizations of all kinds use Fleet [...] today we are only currently able to
> provide fully-managed hosting for deployments **larger than 700 hosts**. (Instead, you can
> buy a license and self-host Fleet Premium with support.)
> Premium features are available either way.

Three facts that matter for the chapter:
1. Managed hosting requires Premium.
2. There is a stated size floor: **more than 700 hosts**.
3. **Premium features are identical on both paths.** The choice is operational, not featural.

The previous stub framed this as a free two-way choice ("With Fleet-hosted, Fleet operates
the control-plane service"). For most readers it is not a choice at all, and saying so is
more useful than describing an option they cannot take.

### Terminology
Fleet's own term is **managed cloud hosting**, not "Fleet-hosted". `docs/Deploy/deploy-fleet.md`
is titled "Hosting Fleet" and says "we can host it for you". Use Fleet's wording.

### Self-hosting deployment targets (documented)
`docs/Deploy/deploy-fleet.md` links guides for: AWS (Terraform), Kubernetes, GCP, Render,
and Docker Compose (described as suitable for a homelab). Also "Try Fleet locally".

### Infrastructure dependencies
`docs/Deploy/Reference-Architectures.md` mention counts: MySQL 34, Redis 29, S3 6.
Consistent with 1.6's three-store model. No new dependency found at this tag.

## 2026-09-04 fix: pilot activity criterion scoped to logged actions (round8 MJ-G)

2.1:156's pilot acceptance criterion "Every action taken during the pilot appears in the activity
record" is falsified by 1.5:102's documented gaps (changing SMTP, the server URL, or the host-expiry
window leaves no entry). Confirmed at fleet-v4.90.0: `server/service/appconfig.go` emits only
named-setting activity types (GitOps mode, account provisioning, Entra tenant/client, activity
automations, and so on) and has no generic config-change activity. Scoped the criterion to the
actions Fleet records and cross-referenced 1.5's known gaps. [[1.5-notes]]
