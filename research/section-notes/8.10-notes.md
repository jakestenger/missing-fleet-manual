## Corrections made in this pass

### 1. Fleet's release notes and Fleet's server disagree on the Android batch size

**Stated, both sides.** `server/config/config.go` registers `mdm.android_batch_size` with a default of **100**, and its own help text repeats it: "Maximum number of hosts per batch for Android MDM API operations (100 default; 0 = no limit)". Fleet's 4.89.0 release note for the same setting says "default: 1000 hosts".

The chapter's §8.10.7 says 100, which is right. Nothing needed changing there.

What was added is a caution under the version table, because the failure mode here is a future editor doing the diligent thing. Someone checking this manual against Fleet's release notes will find a mismatch and "fix" it in the wrong direction. Saying which source was checked, and that the server is the authority, is cheaper than re-deriving it every time.

**This is the ninth Fleet documentation error found by this project**, and the second of the same shape after the config default documented as `1h` that the server registers as `2m`. Not filed, per the standing instruction.

### 2. The version table said "recent" five times

A version table whose entries are dated "recent" tells a reader nothing and ages badly, which is the opposite of what a version table is for. All five were pinned against the changelog: content checksums, the Lock/Wipe/Clear passcode set with `duration=315360000s`, and BYO Unenroll issuing an AMAPI `WIPE` all landed in **4.87.0**; the configurable batch size with staggered install scheduling, and `$FLEET_VAR_HOST_*` in Android profiles and managed app configurations, landed in **4.89.0**.

### 3. An orphaned table row

The certificate retry-budget table in §8.10.10 had its `Renewal` row stranded below the paragraph that follows the table, where it would render as a stray one-row table rather than as part of the table above. Moved back.

A scan for the same defect across the manual found no other instance: no table row anywhere in `manual/` has a non-table line both above and below it.
