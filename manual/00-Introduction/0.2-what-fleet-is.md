# What Fleet is

Fleet is a platform for understanding and managing the computers and mobile devices your organization relies on. It brings device inventory, software, configuration, and security information into one place, so you can see what needs attention and do something about it.

For an administrator, that might mean getting a new colleague’s laptop ready, finding computers that need a browser update, or checking whether disk encryption is enabled. For an operator, it might mean following a rollout, investigating a failed installation, or keeping routine maintenance moving. Fleet connects those jobs through a shared view of each device.

## Know what you have and where to focus

A useful starting point is a question: which devices are running an outdated application? Fleet’s inventory helps you find the installed versions and the hosts that have them. You can also look at hardware and operating-system details, review known vulnerabilities, or run a report when you need a more specific answer.

That view helps with everyday support as well as larger projects. When someone reports a problem with their laptop, you can begin with what Fleet already knows about it. When you plan an upgrade, you can find the affected devices and judge the size of the work before making changes.

Policies turn recurring questions into checks you can follow over time. A policy might check whether a required security setting is enabled, giving you a way to find devices that need attention. As with any information reported by a device, it helps to know when it last checked in, especially if it has been offline.

## Help people get to work

A device becomes useful when it has the applications, settings, and access its user needs. Fleet helps you deliver that setup and maintain it as those needs change. You can distribute software, apply configuration profiles, and use scripts for tasks that need your own instructions. Self-service software gives people a way to install applications you have made available to them.

Imagine preparing laptops for a group of new colleagues. You can organize the devices, choose the appropriate software and settings, and follow their progress as they connect. The same approach carries into later work, such as replacing an application or adjusting a configuration for one group of devices.

You also have a place to return after sending a change. Fleet shows the reported status of the work, helping you decide which devices are ready and which need follow-up. Some will be offline; others may need an administrator to investigate a failed step.

## Make recurring work easier to repeat

Once a task is understood, you can decide how much of it to automate. Fleet’s web interface supports interactive administration, while its API and command-line client, fleetctl, let you connect Fleet to scripts and other systems. GitOps lets you keep supported configuration in version control, where changes can be reviewed and applied through a repeatable process.

These options are useful at different points in the same job. You might investigate a device in the web interface, test a configuration on a small group, then manage that configuration through Git as it becomes part of your standard setup. Policy automations and integrations can help with recurring follow-up, such as responding when a device fails a check.

## Fit Fleet into your environment

Fleet works with macOS, Windows, Linux, iOS, iPadOS, Android, and ChromeOS. The available inventory and management actions vary by platform and by Free or Premium feature. At a high level, Fleet combines software running on computers with the management facilities provided by their operating systems. The later chapters explain which route supports the task you want to carry out.

You can use managed hosting or run the Fleet service yourself. You can also connect it to an identity provider, send data to your security tools, and keep existing systems responsible for work they already handle well. This gives you room to introduce Fleet around a useful first task and expand from there.

If you have a particular job in mind, [How to use this manual](0.3-how-to-use-this-manual.md#where-to-start) will help you find its chapter. It also includes a local preview for exploring Fleet before planning a deployment.
